# HYPR-RACE-V1
Hola, soy nivek. Soy una persona fascinada con el rice y los tiling window managers.

He pasado más de medio año creando y probando esta configuración con la idea de ahorrarles el 90% del trabajo pesado y que puedan disfrutar de un entorno hyprland funcional y estético sin sufrir en el proceso. ¡Espero que les guste!

- **Hyprland:** Gestor de ventanas dinámico con animaciones fluidas y atajos optimizados.
- **Waybar:** Barra superior avanzada con módulos dinámicos y sub-menús interactivos.
- **SwayNC:** Centro de notificaciones elegante con control de volumen y Bluetooth integrados.
- **Rofi (Wayland):** Lanzador de aplicaciones moderno y menú de escritorio.
- **Selector de Fondos Inteligente:** Script minimalista con transiciones suaves para fondos estáticos y animados.
- **Herramientas a medida:** Grabador de pantalla, alertas de batería al vuelo y gestión inteligente de energía.

## Requisitos Previos

Antes de ejecutar el script de instalación, debes instalar las siguientes dependencias en tu sistema:

**1. Repositorios Oficiales (Pacman):**
```bash
sudo pacman -S --needed hyprland hypridle hyprlock waybar rofi swaync swayosd kitty fastfetch btop cava udiskie polkit-gnome gnome-keyring cliphist wl-clipboard hyprsunset swappy pavucontrol blueman playerctl python-gobject gtk-layer-shell ffmpeg imagemagick awww kvantum qt5ct qt6ct nwg-look nwg-displays papirus-icon-theme ttf-jetbrains-mono-nerd inter-font otf-monaspace-nerd grim slurp gpu-screen-recorder brightnessctl firefox thunar thunar-archive-plugin thunar-volman gvfs file-roller tumbler ffmpegthumbnailer xdg-desktop-portal-hyprland xdg-desktop-portal-gtk qt5-wayland qt6-wayland nm-connection-editor network-manager-applet bluez-utils pipewire-pulse libnotify lm_sensors upower
```

**2. Repositorios de la Comunidad (AUR):**
```bash
yay -S --needed mpvpaper ttf-poppins
```

## 🚀 Instalación

1. Clona o descarga este directorio.
2. Entra a la carpeta desde tu terminal:
   ```bash
   cd HYPR-RACE-V1
   ```
3. Ejecuta el instalador mágico:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
4. ¡Cierra tu sesión y vuelve a iniciar seleccionando Hyprland!
